About

pi-dark-factory is an autonomous software factory that turns a PRD into merged pull requests with nobody at the keyboard. It slices a brief into a dependency-ordered backlog, builds each issue unattended behind deterministic verify gates, runs on five cloud machine drivers, and lands everything through a merge queue — roughly 35K lines of code running the loop.
